# Ângulos

Um **ângulo** é a figura geométrica formada por dois **raios** (ou segmentos) que partem de um mesmo ponto chamado **vértice**. Os ângulos são fundamentais para descrever rotações, inclinações, direções e formas geométricas.

## Definição

Ângulo é a abertura entre dois segmentos de reta que se encontram em um ponto comum (vértice).

## Elementos de um Ângulo

### Vértice
O ponto onde os dois lados (segmentos) se encontram.

### Lados (ou Arestas)
Os dois segmentos de reta que formam o ângulo.

## Medida de Ângulos

Os ângulos são medidos em **graus** (°) ou **radianos** (rad).

### Graus (°)
Um círculo completo tem **360°**.

### Radianos (rad)
Um círculo completo tem **2π rad** (≈ 6,28 rad).

### Conversão

$$ 180° = \pi \text{ rad} $$

$$ 1° = \frac{\pi}{180} \text{ rad} \approx 0{,}01745 \text{ rad} $$

$$ 1 \text{ rad} = \frac{180°}{\pi} \approx 57{,}3° $$

## Classificação dos Ângulos

### Por Medida

| Tipo | Medida | Descrição |
|------|--------|-----------|
| **Nulo** | 0° | Lados coincidentes |
| **Agudo** | 0° < α < 90° | Menor que um ângulo reto |
| **Reto** | 90° | Igual a um canto de quadrado |
| **Obtuso** | 90° < α < 180° | Maior que reto, menor que plano |
| **Raso (Plano)** | 180° | Lados formam uma linha reta |
| **Côncavo** | 180° < α < 360° | Maior que um ângulo raso |
| **Completo** | 360° | Volta completa |

```
    Agudo        Reto         Obtuso        Raso
      \          |\           /             _______
       \         | \        /                       
        \        |  \      /                        
         ●       |   ●    ●                         ●________
```

### Por Posição

#### Ângulos Consecutivos
Compartilham um vértice e um lado comum, mas não têm pontos internos em comum.

#### Ângulos Adjacentes
São consecutivos e seus lados não comuns formam uma reta (soma = 180°).

#### Ângulos Opostos pelo Vértice
Formados por duas retas que se cruzam. São **iguais** entre si.

```
       /  \
      /    \
     /  ●   \
    /   /\   \
   /   /  \   \
  /   /    \   \

  α = α' (opostos pelo vértice)
  β = β' (opostos pelo vértice)
```

## Relações entre Ângulos

### Ângulos Complementares
Dois ângulos cuja soma é **90°**.

$$ \alpha + \beta = 90° $$

**Exemplo:** 30° e 60° são complementares.

### Ângulos Suplementares
Dois ângulos cuja soma é **180°**.

$$ \alpha + \beta = 180° $$

**Exemplo:** 120° e 60° são suplementares.

### Ângulos Congruentes
Ângulos com a **mesma medida**.

## Ângulos entre Retas

### Retas Paralelas Cortadas por uma Transversal

Quando duas retas paralelas são cortadas por uma terceira reta (transversal), formam-se vários pares de ângulos especiais:

```
     a / b
   ────/────
      /   c / d
   ────/────
     e / f
```

| Tipo | Definição | Relação |
|------|-----------|---------|
| **Correspondentes** | Mesma posição em cada interseção | São iguais |
| **Alternos internos** | Lados opostos da transversal, entre as paralelas | São iguais |
| **Alternos externos** | Lados opostos da transversal, fora das paralelas | São iguais |
| **Consecutivos internos** | Mesmo lado da transversal, entre as paralelas | São suplementares |
| **Consecutivos externos** | Mesmo lado da transversal, fora das paralelas | São suplementares |

**Consequência:** Se as retas são paralelas, os ângulos correspondentes são iguais. Reciprocamente, se os correspondentes são iguais, as retas são paralelas.

## Ângulos em Polígonos

### Soma dos Ângulos Internos

$$ S_i = (n - 2) \times 180° $$

### Soma dos Ângulos Externos (Convexo)

$$ S_e = 360° $$

### Cada Ângulo Interno (Polígono Regular)

$$ \alpha = \frac{(n-2) \times 180°}{n} $$

## Ângulos no Triângulo

- Soma dos ângulos internos = **180°**
- Um ângulo externo é igual à soma dos dois ângulos internos não adjacentes.

## Ângulos no Quadrilátero

- Soma dos ângulos internos = **360°**

## Ângulos na Circunferência

- **Central:** mede igual ao arco que determina.
- **Inscrito:** mede metade do arco que determina.
- **Ângulo do semicírculo:** sempre **90°**.

## Ângulos na Vida Real

- **Escadas:** ângulo de inclinação ideal ≈ 30-40°
- **Telhados:** inclinação de 15° a 45° dependendo do clima
- **Esqui:** saltos com ângulos de 20-30°
- **Bilhar:** ângulos de incidência e reflexão são iguais
- **Arquitetura:** ângulos de 45° e 90° são muito comuns
- **GPS:** direções medidas em graus a partir do norte (0° = norte, 90° = leste)
