# Conceito de Potenciação

A potenciação é a operação matemática que representa a **multiplicação de fatores iguais**. É uma forma compacta de escrever multiplicações repetidas.

## Notação

$$ a^n $$

- **$a$** → base (o número que está sendo multiplicado).
- **$n$** → expoente (quantas vezes a base é multiplicada).
- **$a^n$** → potência (o resultado).

## Exemplo Básico

$$ 2^4 = 2 \times 2 \times 2 \times 2 = 16 $$

- **2** é a base
- **4** é o expoente
- **16** é a potência

## Significados

1. **Multiplicação repetida**: $3^5 = 3 \times 3 \times 3 \times 3 \times 3 = 243$
2. **Crescimento exponencial**: populações, juros compostos, propagação de vírus.
3. **Geometria**: área de quadrado ($l^2$), volume de cubo ($l^3$).

## Casos Especiais

| Forma | Significado | Exemplo |
|-------|-------------|---------|
| $a^1$ | Própria base | $7^1 = 7$ |
| $a^0$ | Um (se $a \neq 0$) | $5^0 = 1$ |
| $a^2$ | Quadrado | $4^2 = 16$ |
| $a^3$ | Cubo | $3^3 = 27$ |
| $1^n$ | Sempre 1 | $1^{100} = 1$ |
| $0^n$ | Zero (se $n > 0$) | $0^5 = 0$ |

## Atenção

$$ 0^0 \text{ é uma indeterminação (não definido na maioria dos contextos)} $$
