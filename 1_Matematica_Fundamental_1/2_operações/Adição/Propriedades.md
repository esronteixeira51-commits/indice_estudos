# Propriedades da Adição

## 1. Propriedade Comutativa

A ordem das parcelas **não altera** a soma.

$$ a + b = b + a $$

**Exemplo:**
$$ 7 + 3 = 3 + 7 = 10 $$

## 2. Propriedade Associativa

A forma como agrupamos as parcelas **não altera** a soma.

$$ (a + b) + c = a + (b + c) $$

**Exemplo:**
$$ (2 + 5) + 4 = 2 + (5 + 4) = 11 $$

## 3. Elemento Neutro

O número **zero** é o elemento neutro da adição. Somar zero a qualquer número não altera seu valor.

$$ a + 0 = 0 + a = a $$

**Exemplo:**
$$ 9 + 0 = 9 $$

## 4. Fechamento

A soma de dois números naturais é sempre um número natural.

$$ 5 \in \mathbb{N} \text{ e } 3 \in \mathbb{N} \Rightarrow (5 + 3) \in \mathbb{N} $$

## Resumo Visual

| Propriedade | Forma | Significado |
|-------------|-------|-------------|
| Comutativa | $a + b = b + a$ | Ordem não importa |
| Associativa | $(a + b) + c = a + (b + c)$ | Agrupamento não importa |
| Elemento Neutro | $a + 0 = a$ | Zero não altera |
