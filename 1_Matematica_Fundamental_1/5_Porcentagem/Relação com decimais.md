# Relação com Decimais

A porcentagem tem uma relação direta e simples com os números decimais: basta **dividir por 100** (ou mover a vírgula duas casas para a esquerda) para converter de porcentagem para decimal.

## Regra Fundamental

$$ p\% = \frac{p}{100} = p \div 100 $$

## Convertendo Porcentagem → Decimal

**Mova a vírgula duas casas para a esquerda** e retire o símbolo %:

| Porcentagem | Cálculo | Decimal |
|-------------|---------|---------|
| 1% | $1 \div 100$ | 0,01 |
| 5% | $5 \div 100$ | 0,05 |
| 10% | $10 \div 100$ | 0,10 |
| 12,5% | $12,5 \div 100$ | 0,125 |
| 25% | $25 \div 100$ | 0,25 |
| 50% | $50 \div 100$ | 0,50 |
| 75% | $75 \div 100$ | 0,75 |
| 100% | $100 \div 100$ | 1,00 |
| 150% | $150 \div 100$ | 1,50 |
| 200% | $200 \div 100$ | 2,00 |
| 0,5% | $0,5 \div 100$ | 0,005 |
| 0,1% | $0,1 \div 100$ | 0,001 |

## Convertendo Decimal → Porcentagem

**Mova a vírgula duas casas para a direita** e acrescente o símbolo %:

| Decimal | Cálculo | Porcentagem |
|---------|---------|-------------|
| 0,01 | $0,01 \times 100$ | 1% |
| 0,05 | $0,05 \times 100$ | 5% |
| 0,10 | $0,10 \times 100$ | 10% |
| 0,125 | $0,125 \times 100$ | 12,5% |
| 0,25 | $0,25 \times 100$ | 25% |
| 0,50 | $0,50 \times 100$ | 50% |
| 0,75 | $0,75 \times 100$ | 75% |
| 1,00 | $1,00 \times 100$ | 100% |
| 1,50 | $1,50 \times 100$ | 150% |
| 2,00 | $2,00 \times 100$ | 200% |
| 0,005 | $0,005 \times 100$ | 0,5% |
| 3,14 | $3,14 \times 100$ | 314% |

## A Regra da Vírgula

```
Porcentagem → Decimal: vírgula 2 casas para a ESQUERDA
   45%  →  0,45
  120%  →  1,20
    7%  →  0,07
  0,5%  →  0,005

Decimal → Porcentagem: vírgula 2 casas para a DIREITA
  0,45  →  45%
  1,20  →  120%
  0,07  →  7%
  0,005  →  0,5%
```

## Triângulo de Conversão: Porcentagem ↔ Fração ↔ Decimal

| Porcentagem | Fração | Decimal |
|-------------|--------|---------|
| 1% | $\frac{1}{100}$ | 0,01 |
| 5% | $\frac{1}{20}$ | 0,05 |
| 10% | $\frac{1}{10}$ | 0,10 |
| 12,5% | $\frac{1}{8}$ | 0,125 |
| 20% | $\frac{1}{5}$ | 0,20 |
| 25% | $\frac{1}{4}$ | 0,25 |
| 33,33...% | $\frac{1}{3}$ | 0,333... |
| 50% | $\frac{1}{2}$ | 0,50 |
| 66,67...% | $\frac{2}{3}$ | 0,666... |
| 75% | $\frac{3}{4}$ | 0,75 |
| 80% | $\frac{4}{5}$ | 0,80 |
| 100% | $1$ | 1,00 |

## Porcentagem como Decimal em Cálculos

Calcular "25% de 80" usando decimal:

$$ 25\% \times 80 = 0{,}25 \times 80 = 20 $$

Isso é frequentemente mais rápido que usar a fração $\frac{25}{100}$.

## Decimais e Porcentagem na Calculadora

Na calculadora científica:
- Para calcular %: geralmente existe uma tecla `%`
- Ou converta para decimal manualmente: `25% = 0.25`

## Atenção: Números Maiores que 100%

Quando a porcentagem é maior que 100%, o decimal é maior que 1:

- $150\% = 1{,}5$ (um e meio vezes o original)
- $200\% = 2{,}0$ (dobro do original)
- $300\% = 3{,}0$ (triplo do original)
