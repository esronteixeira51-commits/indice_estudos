# Igualdade

A **igualdade** é uma relação fundamental da álgebra que indica que duas expressões têm o mesmo valor. É representada pelo símbolo **=** (sinal de igual).

## Definição

Uma igualdade afirma que duas expressões possuem o **mesmo valor numérico**:

$$ a = b $$

Significa: "a tem o mesmo valor que b".

## Tipos de Igualdade

### 1. Igualdade Numérica (Verdadeira)

Ambos os lados são números conhecidos e têm o mesmo valor:

$$ 5 + 3 = 8 $$

$$ 12 \div 4 = 3 $$

$$ 2^3 = 8 $$

### 2. Igualdade Algébrica (Identidade)

Válida para **qualquer valor** das variáveis:

$$ a + b = b + a \quad \text{(comutativa da adição)} $$

$$ (a + b)^2 = a^2 + 2ab + b^2 $$

$$ x + x = 2x $$

**Teste:** $x + x = 2x$ para $x = 5$: $5 + 5 = 10$ e $2 \times 5 = 10$ ✓

### 3. Igualdade Condicional (Equação)

Válida apenas para **alguns valores** específicos:

$$ x + 3 = 7 $$

Só é verdade quando $x = 4$.

$$ x^2 = 9 $$

Só é verdade quando $x = 3$ ou $x = -3$.

## Propriedades da Igualdade

### 1. Reflexiva

$$ a = a $$

Qualquer coisa é igual a si mesma.

### 2. Simétrica

$$ \text{Se } a = b \text{, então } b = a $$

Se $5 + 3 = 8$, então $8 = 5 + 3$.

### 3. Transitiva

$$ \text{Se } a = b \text{ e } b = c \text{, então } a = c $$

Se $x = 5$ e $5 = y$, então $x = y$.

### 4. Adição

$$ \text{Se } a = b \text{, então } a + c = b + c $$

Podemos somar o mesmo número dos dois lados.

**Exemplo:**

$$ x = 5 $$
$$ x + 3 = 5 + 3 $$
$$ x + 3 = 8 $$

### 5. Subtração

$$ \text{Se } a = b \text{, então } a - c = b - c $$

Podemos subtrair o mesmo número dos dois lados.

### 6. Multiplicação

$$ \text{Se } a = b \text{, então } a \times c = b \times c $$

Podemos multiplicar os dois lados pelo mesmo número.

### 7. Divisão

$$ \text{Se } a = b \text{ e } c \neq 0 \text{, então } a \div c = b \div c $$

Podemos dividir os dois lados pelo mesmo número (diferente de zero).

## Igualdade vs. Equação

| Conceito | Significado | Exemplo |
|----------|-------------|---------|
| **Igualdade numérica** | Afirmação verdadeira com números | $5 + 3 = 8$ |
| **Identidade** | Igualdade verdadeira para todos os valores | $(a+b)^2 = a^2 + 2ab + b^2$ |
| **Equação** | Igualdade que só é verdade para alguns valores | $x + 2 = 7$ (só para $x = 5$) |

## Notação de Igualdade

| Símbolo | Significado | Exemplo |
|---------|-------------|---------|
| $=$ | É igual a | $2 + 2 = 4$ |
| $\neq$ | É diferente de | $3 + 2 \neq 6$ |
| $\approx$ | É aproximadamente igual a | $\pi \approx 3{,}14$ |
| $\equiv$ | É idêntico a (identidade) | $a + b \equiv b + a$ |

## Igualdade e Balança

Imagine uma **balança** em equilíbrio:

```
    [ 3 + 5 ]     =     [ 8 ]
         ↓                 ↓
    ─────┬─────       ─────┬─────
         │                 │
    ═════╧═════       ═════╧═════
           \             /
            \           /
             \         /
              \       /
               \     /
                \   /
                 \ /
                  ▼
              EQUILÍBRIO
```

Se você adicionar algo a um lado, deve adicionar o mesmo ao outro para manter o equilíbrio.

## Verificando uma Igualdade

Para verificar se $x = 3$ é solução de $2x + 1 = 7$:

Substitua $x = 3$:

$$ 2(3) + 1 = 6 + 1 = 7 $$

$$ 7 = 7 \quad \text{✓ Verdade!} $$
