# Conceito de Fração

Uma fração representa uma **parte de um todo** que foi dividido em partes iguais. É uma forma de expressar uma divisão ou uma relação entre duas quantidades.

## Notação

Uma fração é escrita na forma:

$$ \frac{a}{b} $$

Onde:
- **$a$** → numerador (parte que se considera)
- **$b$** → denominador (número de partes iguais em que o todo foi dividido)

## Exemplo Básico

Imagine uma pizza dividida em **4 fatias iguais**:

- Se comer **1 fatia**, comeu **$\frac{1}{4}$** da pizza.
- Se comer **3 fatias**, comeu **$\frac{3}{4}$** da pizza.
- Se comer **4 fatias**, comeu **$\frac{4}{4} = 1$** (a pizza inteira).

## Significados de uma Fração

1. **Parte de um todo**: "$\frac{2}{5}$ de uma torta"
2. **Divisão**: "$\frac{3}{4}$ significa $3 \div 4$"
3. **Razão**: "2 para 3" → $\frac{2}{3}$
4. **Número na reta numérica**: está entre 0 e 1 (ou além, se maior que 1)

## Tipos de Frações

| Tipo | Definição | Exemplo |
|------|-----------|---------|
| **Própria** | Numerador < Denominador | $\frac{3}{5}$ |
| **Imprópria** | Numerador ≥ Denominador | $\frac{7}{4}$ |
| **Aparente** | Numerador é múltiplo do denominador | $\frac{6}{2} = 3$ |
| **Mista** | Número inteiro + fração própria | $1\frac{3}{4}$ |
| **Unitária** | Numerador = 1 | $\frac{1}{8}$ |
| **Decimal** | Denominador é potência de 10 | $\frac{3}{100}$ |

## Frações na Reta Numérica

```
0        1/4      1/2      3/4       1
|--------+--------+--------+--------+|
```

## Fração como Número

Toda fração é um número! $\frac{1}{2} = 0{,}5$ e $\frac{3}{4} = 0{,}75$. Frações e decimais são representações diferentes do mesmo valor.
